# SORAZUM MVP

SORAZUM — платформа коллективного разума для решения реальных оплачиваемых задач.

Компании и государство размещают миссии, люди сами присоединяются, а ИИ собирает несколько сильных команд, сравнивает их материалы и помогает объединить лучшие совместимые части в один результат.

## Возможности MVP

- глобальный каталог миссий с поиском, фильтрами, сортировкой и избранным;
- подробная карточка задачи с результатом, правилами и схемой выплаты;
- вступление без отбора и интерактивная ИИ-сборка международной команды;
- полноценное рабочее пространство: канбан-задачи, команда и чат;
- пошаговый AI-синтез с прозрачной связью результата и авторов;
- экран вклада участника и прогнозируемой выплаты;
- мастер публикации миссии для компаний и государства;
- сохранение пользовательских действий в браузере;
- адаптивный интерфейс для смартфонов, планшетов и ноутбуков.

## Запуск в Cursor

```bash
npm install
npm run dev
```

После запуска откройте `http://localhost:3000`.
